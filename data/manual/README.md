# 수동 구조화 데모 정책 (API 비용 0)

실제 공고문을 손으로 옮긴 데이터. 온통청년 API 키나 Anthropic API 키 없이 A2 → 빌더 →
판정 API 까지 실데이터로 돌려보기 위한 것이다.

```
raw/page-001.json   온통청년 API 응답과 같은 모양의 레코드 (출처는 각 refUrlAddr1)
a2/<plcyNo>.json    A2 출력 계약(batch/agents/contract.py)에 맞춰 사람이 작성한 구조화 응답
```

```bash
python -m batch.agents.cli structure data/manual/raw --responses data/manual/a2 -o data/manual/policies.json
python -m batch.build_snapshot data/manual/policies.json -o data/manual/snapshot.json
SNAPSHOT_PATH=data/manual/snapshot.json uvicorn app.main:app
```

`a2/` 의 응답은 모델 응답과 **완전히 같은 검증**(인용문 원문 대조 · API 코드 룰과의 불일치 ·
`validate_policy`)을 거친다. 손으로 썼다고 통과가 보장되지 않으며, 그래야 이 데이터로
검증 경로 자체를 시연할 수 있다.

## ⚠️ 시나리오 5(중복수혜 조합)는 지금 이 데이터로 돌지 않는다

상충 쌍이었던 국토부 청년월세의 **신청기간이 2026-05-29 에 실제로 끝났다.** 기간이 지난
정책은 판정과 조합에서 제외되므로(`docs/HANDOFF.md` §3 "마감 여부는 status 가 아니라
날짜로 판단한다"), 소득 55% 가평 사용자에게 동시 적격인 정책이 하나뿐이 되어 보수·최대
두 안이 같아진다.

**기능이 깨진 게 아니라 데이터가 만료된 것이다.** 국토부 정책이 열려 있던 날짜로 돌리면
그대로 나온다:

| | 조합 |
| --- | --- |
| 보수 | 4,800,000원 = 국토부 단독 (가평은 `ESTIMATED` 상충으로 제외, 원문 인용 첨부) |
| 최대 | 5,400,000원 = 둘 다 |

`tools/demo_scenario.py` 의 D-2 가 두 안이 같으면 그 사실을 출력한다 — 상충이 없는
조합도 같은 모양이라, 말해주지 않으면 시연 중에 정상처럼 보인다.

**복구하려면** 신청기간이 열려 있는 **전국 또는 경기 단위 주거 정책 1건**이 더 필요하다.
가평 월세는 지역 조건이 `41820` 이라, 상대는 전국(`00`)이거나 경기(`41`) 단위여야 한 사용자가
둘 다 적격이 된다. `ONTONG_API_KEY` 로 최신 수집을 하거나 실제 공고를 손으로 옮기면 된다.

그동안 시나리오 5 는 **합성 데이터(`data/demo/`)로 돌고, `tests/e2e` 가 단언한다**
(보수 3,000,000원 vs 최대 3,200,000원). 회귀는 막혀 있고, 실공고 시연만 비어 있다.

## 나머지 시나리오

E2E 시나리오 1·2·3·4·6 은 이 5건으로 그대로 돈다. 덤으로 **마감 정책이 판정에서 빠지는
것**도 이 데이터로 보여줄 수 있다 — 국토부 정책이 빌드 리포트에 `미게시 1건 (expired 1)`
로 남는다.
E2E 시나리오 1~6 이 전부 이 11건으로 돈다. 골든 정답표(`tests/golden/a2_expected.json`)도 11건.

주의: API 는 구가 있는 시를 구 코드로 준다(용인 `41461,41463,41465`). 사용자 지역도 구 코드여야 맞는다 — HANDOFF §8 #15.
