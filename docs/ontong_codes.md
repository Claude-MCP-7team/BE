# 온통청년 OPEN API 코드표

`https://www.youthcenter.go.kr/go/ythip/getPlcy` 응답의 코드값 의미다.
**운영기관이 배포한 공식 문서를 옮긴 것**이고, `batch/collect/normalize.py` 의
코드 매핑이 여기서 온다.

처음에는 실응답 2,774건의 자유 텍스트와 대조해 추정했다. 2026-09-24 에 이 표를
받아 전부 확인했고 추정이 틀린 건 없었다.

**코드 의미를 안다고 전부 매핑하지는 않는다.** 우리 enum 에 정확히 대응하는 것만
룰로 만든다 — 자세한 이유는 `normalize.py` 도크스트링에 있다.
